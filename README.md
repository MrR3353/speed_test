# speed_test

Скрипт для измерения средней скорости скачивания из интернета. Делает несколько
последовательных запросов к указанному адресу (например, тяжёлой картинке) и
печатает в консоли статистику по каждому запросу и средние показатели.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Использование

```bash
python main.py [url] [-n REQUESTS_NUM]
```

- `url` — адрес файла для скачивания (необязательный, по умолчанию используется
  встроенная тестовая картинка).
- `-n, --requests-num` — количество последовательных запросов (по умолчанию 10).

Примеры:

```bash
python main.py
python main.py https://example.com/big-image.jpg
python main.py https://example.com/big-image.jpg -n 20
```

## Вывод

Для каждого запроса выводится размер, время и скорость скачивания, а в конце —
суммарный объём данных, среднее время запроса и средняя скорость скачивания
в МиБ/с (MiB/s).
